- lekside-logo-light.svg: transparent horizontal logo for light backgrounds

- favicon-light.svg: light square browser icon

Brand colors:

- Gray: #A8A8A8

SVGs are transparent and scale cleanly. To use favicon.svg, place it in your public folder and add:
<link rel="icon" type="image/svg+xml" href="/favicon.svg" />

Note: these are clean vector redraws of the concept, not traced pixels from the generated preview sheet. Check visual fit at your intended size before shipping.
